## Problem Statement
Evidence-Based Operator Network Fault Localisation

## Project Overview
NetworkFault AI is a proposed platform designed to help network operators identify potential network faults by correlating diagnostic evidence such as latency, packet loss, ping results, and available network logs.

## Objectives
- Analyse available network diagnostic evidence.
- Identify and narrow down suspected fault locations.
- Present supporting evidence and communicate uncertainty.
- Recommend additional verification tests.
- Use AI to help explain diagnostic findings.

## Proposed Technology Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Python, FastAPI
- **Network Diagnostics:** Ping, traceroute, and connectivity checks
- **Data & Visualisation:** Network measurements and diagnostic charts
- **AI Integration:** AI-assisted explanations of diagnostic evidence
